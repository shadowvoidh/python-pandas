# Atividade Prática: Tabelas, Limpeza de Dados e Gráficos

Projeto prático desenvolvido em Python utilizando as bibliotecas **pandas**, **numpy** e **matplotlib** para manipulação, tratamento de dados faltantes e geração de visualizações gráficas.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Pandas**: Criação, consulta e limpeza do DataFrame.
- **NumPy**: Representação de valores nulos (`np.nan`).
- **Matplotlib**: Construção de histogramas, gráficos de dispersão e barras.

## 📋 Conteúdo do Projeto
1. **Consulta e Filtros**: Inspeção de dados, tipos de colunas e filtragem por condições.
2. **Tratamento de Texto**: Remoção de espaços em branco com `.str.strip()`.
3. **Tratamento de Dados Faltantes**: Comparação entre remoção (`dropna`) e imputação por média/mediana (`fillna`).
4. **Mapeamento de Dados**: Substituição de categorias texto por códigos numéricos.
5. **Visualização de Dados**: Gráficos de dispersão, histogramas e barras (IMC e peso por turma).
6. **Desafio (pd.cut)**: Agrupamento do IMC em faixas e análise de contagem.

## 🚀 Como Executar
1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
```

Execute o script principal:

```Bash
python src/main.py
```
